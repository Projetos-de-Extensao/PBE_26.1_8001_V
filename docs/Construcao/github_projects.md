# GitHub Projects

> Organização do desenvolvimento utilizando o GitHub Projects como quadro Kanban.

## Metodologia

O projeto seguiu a metodologia UP/RUP (Unified Process) com iterações incrementais, organizadas em um quadro Kanban no GitHub Projects com as seguintes colunas:

| Coluna | Descrição |
|---|---|
| **Backlog** | Tarefas identificadas mas ainda não priorizadas |
| **To Do** | Tarefas priorizadas para a iteração atual |
| **In Progress** | Tarefas em desenvolvimento ativo |
| **Review** | Tarefas aguardando revisão de código |
| **Done** | Tarefas concluídas e integradas à branch main |

## Iterações do Projeto

### Iteração 1 — Iniciação (Semanas 1-4)
- Definição do problema e escopo
- Pesquisa e brainstorming
- Criação do 5W2H e mapa mental
- Design Thinking
- Protótipo de baixa fidelidade
- Documentação inicial (MkDocs)

### Iteração 2 — Elaboração (Semanas 5-8)
- Levantamento de requisitos (RF01-RF07, RNFs)
- Diagramas de casos de uso (FUNC1-FUNC13)
- Diagrama de classes (12 entidades)
- Diagramas de sequência
- Documento de visão
- Documento de arquitetura (DAS)

### Iteração 3 — Construção (Semanas 9-14)
- Setup do projeto Django + DRF
- Implementação dos models
- Serializers e ViewSets
- Autenticação JWT
- Documentação Swagger/OpenAPI
- Permissões por perfil
- Lógica de processo (@actions, perform_create)
- Testes unitários e de integração

### Iteração 4 — Transição (Semanas 15-16)
- Correção de bugs identificados nas reanálises
- Preenchimento de documentação pendente
- Verificação final
